# Glow Guide

Glow Guide עוזרת לגלות מוצרי טיפוח, לבדוק את הרכיבים שלהם ולשמור מוצרים בשגרה אישית.

## עמודים

- **כל המוצרים (`/`)** — צפייה במוצרים וחיפוש לפי שם.
- **פרטי מוצר (`/items/:id`)** — צפייה בתמונה, בשם, במותג וברשימת הרכיבים.
- **השגרה שלי (`/routine`)** — צפייה במוצרים שסומנו בלב ונשמרו בדפדפן.
- **בודקת רכיבים (`/ingredients`)** — חיפוש מוצרים לפי רכיב.
- **השוואה (`/compare`)** — השוואה בין עד שלושה מוצרים, כולל רכיבים משותפים.
- **עמוד 404** — מוצג בכניסה לכתובת שאינה קיימת, עם קישור לדף הבית.

## תכונות

- חיפוש מוצרים לפי שם או לפי רכיב.
- סינון "נקי מ..." לפי בישום, אלכוהול או פרבנים.
- התאמה לבעיות עור והסבר אילו רכיבים זוהו כמתאימים.
- אזהרות על שילובי רכיבים שלא מומלץ לשלב בין מוצרים בשגרה.
- השוואה של עד שלושה מוצרים, כולל מציאת הרכיבים המשותפים להם.
- שמירת המוצרים בשגרה ב־`localStorage`.

## התקנה והרצה

```bash
npm install
npm run dev
```

## בדיקות

```bash
npm test
npm run test:ui
```

`npm run test:ui` מציג בטרמינל כתובת עם token; יש לפתוח את הכתובת הזו בדפדפן כדי להשתמש בממשק הבדיקות.

## מקור הנתונים

המוצרים מגיעים מ־[Open Beauty Facts API](https://world.openbeautyfacts.org/api/v2/search?categories_tags_en=face-creams&fields=code,product_name,brands,image_front_url,ingredients_text&page_size=100). מוצגים רק מוצרים עם שם, תמונה ורשימת רכיבים. ההתאמה לבעיות עור, הסינון "נקי מ..." וההתנגשויות בשגרה הן לוגיקה של האפליקציה שבודקת את רשימת הרכיבים שמגיעה מה־API, ולא מידע מוקלד על מוצרים. זה מידע כללי ואינו ייעוץ רפואי.

## טכנולוגיות
